Frete — como funciona

Brasil (Mini Envios e outras modalidades)

  • Com Correios configurados (CORREIOS_USER + CORREIOS_PASSWORD + cartão ativo): cotação real via API dos Correios.
  • Sem credenciais ou contrato pendente: estimativa fixa por distância de CEP (R$ 11,90 a R$ 24,90). O checkout continua funcionando.
  • Modalidades ativas: Admin → aba Frete → “Modalidades de envio”.

Internacional

  • Cotação em tempo real: simulador Exporta Fácil dos Correios.
  • Se a API falhar: tabela fallback no admin (sincroniza automaticamente quando a API responde).

Status na aba API do admin

  • ✓ Conectado
  • ⚠ Aviso (sandbox, fallback, sem credenciais com estimativa)
  • ✗ Erro (credencial inválida ou serviço indisponível)
  • — Não configurado

Correios — passo a passo

  1. Cadastro Meu Correios com CNPJ da 3N20 (29321223000132, sem pontuação).
  2. Gerar código da API em CWS → Gestão de acesso a APIs. Solicitar APIs 34 (Preço), 35 (Prazo) e 36 (Pré-Postagem).
  3. Contratar Clube Correios em Correios Empresas (aguardar até 2 dias úteis).
  4. Cartão de postagem: empresas.correios.com.br → Meus Contratos → Cartões de Postagem. Anotar o cartão (10 dígitos) e o contrato comercial.
  5. Pedir ao gestor Correios os serviços no cartão: 04227 (Mini Envios), 86720 (Pré-Postagem API) e 8010 (Carta Registrada, se usar).
  6. Secrets no Worker: CORREIOS_USER (CNPJ), CORREIOS_PASSWORD (código CWS), CORREIOS_CONTRACT (cartão), CORREIOS_COMMERCIAL_CONTRACT (contrato comercial).
  7. Validar: Admin → aba API → Correios BR ✓; Frete → Correios BR → testar CEP 01310-100.

Inscrição estadual (se pedirem no contrato): consulta pública CADESP. Se não houver IE ativa, use ISENTO.

Cupons e comissionados

Cupons dão desconto ao cliente e podem ter um comissionado vinculado (influencer, parceiro) que recebe e-mail automático a cada venda.

Como criar um cupom

  1. Admin → aba Cupons → Novo cupom.
  2. Defina: código (ex.: MEUKIT10), desconto (% ou R$), validade opcional e limite de usos.
  3. Para cupom com comissão: preencha nome, e-mail e percentual do comissionado.
  4. Salvar — o cupom fica ativo imediatamente no checkout.

Como funciona no checkout

  • Cliente digita o código → desconto aplicado em tempo real.
  • Após pagamento confirmado, o Worker envia e-mail ao comissionado com o valor da comissão.
  • Pedido gravado com campos: couponCode, couponDiscount, couponCommissionAmount.

Página pública de cadastro de comissionados

comissionado.html — formulário público para interessados se candidatarem a virar comissionado. O admin aprova manualmente depois.

Cálculo financeiro por pedido

Cada venda normalizada armazena: gross (bruto), fees (tarifas/comissão), shipping (frete líquido cobrado pelo marketplace ao vendedor), liquid (valor que cai na conta). A fórmula é:

liquid = gross − fees − shipping

Módulos relevantes: api/ml-settlement.js (ML), api/shopee-settlement.js (Shopee), api/order-financials.js (geral).

Flex ML — a pagar

Vendas Mercado Livre com frete Flex (entrega no mesmo dia pelo próprio vendedor) têm custo de frete pago pela empresa. O consolidado exibe o total que a empresa deve ao longo do mês.

Como ver

Admin → aba Vendas → seção Flex a pagar (colapsável). Mostra por mês: quantidade de vendas Flex, valor do frete, bônus ML e líquido.

Como é calculado

  • Custo Flex ao vendedor: mlFlexShippingCost configurável em Admin → Frete → campo "Custo Flex por envio (R$)".
  • Bônus ML: ML paga bônus para incentivar o Flex — calculado via mlFlexBonusFromCosts() em api/ml-settlement.js.
  • Líquido: custo − bônus. Valor negativo = empresa ainda deve; positivo = ML cobriu mais que o custo.

Exportação

Excel exportado em Vendas → Exportar inclui aba Flex a pagar com o mesmo detalhamento mensal.

Settlement de frete ML (técnico)

Módulo api/ml-settlement.js (versão ML_SETTLEMENT_VERSION = 9). A fonte de frete é determinada por prioridade:

  1. senders[].cost da API de custos de envio (/shipments/{id}/costs) — fonte preferencial.
  2. Repair de Envios já-net (repairEnviosAlreadyNet) quando o custo já descontou o valor do comprador.
  3. Fallback: fórmula implícita gross − fees − liquid.
  4. Não resolvido (source: null) — exibido como "frete não identificado" no consolidado.

Comunidade (fórum)

Espaço onde clientes e usuários discutem dúvidas, dicas e experiências com o produto. Disponível em comunidade.html.

Controle de acesso

  • Modo beta (padrão): só usuários com flag tester veem a comunidade.
  • Liberar para todos: Admin → aba Comunidade → toggle "Liberar comunidade para todos". Altera a config forumPublic: true no KV.
  • Usuários tester: cadastro com pedido de R$ 0,01 no checkout; dão acesso à comunidade beta e ao conteúdo em desenvolvimento.

Gerenciamento (aba Comunidade no admin)

  • Atualizar: recarrega lista de tópicos e usuários.
  • Atualizar tópicos exemplo (dores reais): faz seed de tópicos iniciais com perguntas frequentes reais — útil para popular o fórum antes de liberar.
  • Verificar tópico relacionado: busca se já existe tópico semelhante ao que um usuário quer postar — evita duplicatas.
  • Abrir página: abre comunidade.html em nova aba.

Estrutura técnica

  • Tópicos e respostas armazenados no Cloudflare KV com chaves forum:topic:{id} e forum:reply:{id}.
  • Busca semântica de tópicos relacionados via endpoint GET /admin/forum/related?q=….
  • Moderação e deleção via Admin — sem necessidade de acessar o KV diretamente.

O que é “Acesso direto”?

O site não conseguiu identificar de onde a pessoa veio. Na prática, costuma ser:

  • Digitou sensortattoofix.com.br na barra do navegador
  • Favorito / bookmark
  • Link em WhatsApp, Telegram ou e-mail (muitos apps não enviam origem)
  • QR code ou cartão de visita
  • Bot, monitoramento ou servidor (também aparece assim)

Não dá para saber com certeza qual desses foi — só que não veio de anúncio rastreado nem de link com origem registrada.

Exemplo de jornada no log

Google Ads  →  Entrada — Home  →  Entrada — Loja  →  Entrada — Checkout

Interpretação: clicou no anúncio, navegou e chegou ao checkout. Ainda não é venda — confira em Pedidos se virou pedido pago.

Cores — duas colunas diferentes

  • Centro (verde): tipo de página ou clique (Entrada — Home, Mercado Livre…).
  • Direita (badge): origem do tráfego na primeira entrada da visita (Acesso direto, Google Ads…).

Nota técnica (jun/2026): em versões anteriores, “Acesso direto” podia aparecer em cinza ou amarelo para a mesma situação (bug ao salvar o referrer humanizado). Corrigido no admin — acesso direto fica sempre cinza; amarelo reservado para link de outro site.

Dicas

  • Passe o mouse sobre a linha para ver tooltip (campanha UTM, referrer, dispositivo).
  • Use Exportar Excel para análise por dia/semana/mês.
  • Testar log grava evento de diagnóstico — use Limpar testes depois.
  • Métricas agregadas também existem no Google Analytics 4.
